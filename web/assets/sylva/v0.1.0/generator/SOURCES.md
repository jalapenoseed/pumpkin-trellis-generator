# Sources & photo reference

Botanical dimensions and descriptions come from the extension and dendrology pages below. They were fetched and read while building the presets. The Pagosa-area context comes from the local pages linked in the original brief.

> **Photo libraries:** the *Wikimedia Commons* category links are built from the standard `Category:<Genus_species>` pattern and have **not** been opened yet. The build environment can't download images, so check each link and pull photo reference from it before relying on it.

Fall colour palettes are art-directed from these descriptions. The weights (share of leaves per colour) are tunable in each species TOML.
